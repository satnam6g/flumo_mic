Download Wireless Mic

Get the free Android app and Windows client. No accounts, no subscriptions — just download, pair, and start streaming encrypted audio.

Windows Desktop Client

v2.0

The lightweight receiver that turns your PC into an encrypted audio endpoint. QR pairing, audio controls (gain / noise gate / monitor), recording, and auto VB-Cable setup.

Download for Windows
  • Windows 10 or 11 (64-bit)
  • Python 3.10+ (bundled)
  • ~17 MB download
  • VB-Audio Virtual Cable (included)

Android App

v2.0

The sender app that captures studio-quality 48kHz audio from your phone's microphone and streams it with real-time AES-256 encryption. Scan-to-pair QR setup, background & screen-off streaming, Bluetooth headset mic support, auto-reconnect, plus a home-screen widget and Quick Settings tile.

Download APK
  • Android 10.0 or higher
  • Microphone permission required
  • Same Wi-Fi network as your PC
  • ~62 MB download

Version History

v2.0.1 — Latest Release (Stability Patch)

Released August 2026

  • Patch release on top of v2.0 — packaging and stability improvements
  • Includes everything from v2.0: QR pairing, audio controls, recording, hotkeys
  • Upgrading from v1.x? Uninstall the old Android app first (signing changed in v2.0)

v2.0 — QR Pairing & Audio Controls (Biggest Upgrade)

Released August 2026

  • QR pairing — scan the code on the Windows client, IP + PIN filled automatically
  • Persistent PIN — same code every launch, regenerate anytime
  • Audio controls: gain, noise gate, mute, live monitor + one-click WAV recording
  • Global hotkeys (Ctrl+Alt+M / R / S) and auto-start with Windows
  • Auto-reconnect, multi-device mixing, live loss % / jitter stats
  • Android: Bluetooth headset mic, phone-side gain + mute, home widget + Quick Settings tile

v1.0.1 — Performance & Automatic Driver Setup Release

Released July 2026

  • Added auto-detection and silent helper installer for VB-Audio Virtual Cable
  • Optimized UDP audio packet streaming buffer and reduced latency
  • Enhanced UI real-time audio meter peak indicators and network connection status
  • Improved Android high-priority audio capture thread stability and background wake-lock handling

v1.0.0 — Initial Release

Released May 2025

  • AES-256 CBC encryption with PIN-based key derivation
  • 48kHz, 16-bit PCM mono audio capture
  • UDP streaming over Wi-Fi with ~20ms latency
  • VB-Audio Virtual Cable integration for universal app support
  • Dark and light theme support in the Android app
  • USB tethering support as an alternative to Wi-Fi

Coming Soon in v2.1

Features approved for the next release — follow the repository to catch them the moment they ship:

  • AI Noise Suppression — adaptive background-noise removal for crystal-clear voice
  • Compression mode — bandwidth saver for congested or slower networks
