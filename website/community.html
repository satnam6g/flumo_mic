How to Contribute

Wireless Mic is built with Flutter (Dart + Kotlin) for the Android app and Python for the Windows client. Here's how to set up the development environment:

Prerequisites

  • Android App: Flutter SDK 3.10+, Android SDK with API 30+, a physical Android device with USB debugging
  • Windows Client: Python 3.10+, PyAudio, PyCryptodome

Quick Start

# Clone the repository
git clone https://github.com/satnam6g/flumo_mic.git
cd flumo_mic

# Windows Client
cd windows_client
pip install -r requirements.txt
python main.py

# Android App (in a separate terminal)
cd android_app
flutter pub get
flutter run

For detailed architecture documentation, see the Technical Wiki.
