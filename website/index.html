Under the Hood

Technical specifications for developers and power users. Full technical wiki →

AES-CBC Security

PIN-Protected Encryption

  • Algorithm: AES-256 CBC (Cipher Block Chaining)
  • Key Derivation: SHA-256 hash of your 4-digit PIN
  • Initialization Vector: 16-byte random IV per packet
  • Padding: PKCS7 standard padding

Every audio packet is individually encrypted before transmission. Learn more about our security architecture →

Lossless Audio Capture

  • Sample Rate: 0 Hz
  • Bit Depth: 0-bit
  • Channels: Mono (Microphone Standard)
  • Codec: Raw PCM (uncompressed, zero artifacts)

Latency: ~20ms

Real-Time UDP Streaming

  • Protocol: UDP (User Datagram Protocol)
  • Port: 55555 (default)
  • Packet Size: ~4800 bytes (~100ms of audio)
  • Error Handling: Automatic drop of out-of-order packets

System Compatibility

  • Windows: 10 / 11 (64-bit)
  • Android: 10.0 or higher
  • Network: Same local Wi-Fi or USB tethering
  • Audio Driver: VB-Audio Virtual Cable (included in setup)
